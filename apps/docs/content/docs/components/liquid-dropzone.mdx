
</Tab>

```npm

```

</Tab>

## Usage

```tsx
import { LiquidDropzone } from "@/components/liquid-dropzone"
```

```tsx
<LiquidDropzone maxFiles={20} />
```

Two wave layers loop at different speeds for depth. The level reads from `useUploadProgress`, so it works for any number of files. Waves stop with `prefers-reduced-motion`.
