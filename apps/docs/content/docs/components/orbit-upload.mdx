## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/orbit-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="orbit-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { OrbitUpload } from "@/components/orbit-upload"
```

```tsx
<OrbitUpload accept="image/*" />
```

Up to eight files orbit at once; the rest wait in the queue. Orbiting stops with reduced motion.
