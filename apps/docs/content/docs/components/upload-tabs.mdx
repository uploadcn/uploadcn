## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/upload-tabs
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and the shadcn `input`, `tabs` components, then copy:

<ComponentSource name="upload-tabs" />

<ComponentSource name="use-camera" />

</Tab>
</Tabs>

## Usage

```tsx
import { UploadTabs } from "@/components/upload-tabs"
```

```tsx
<UploadTabs sources={["device", "link"]} />
```

Links are fetched in the browser and uploaded like any other file, so the source must allow CORS. The camera starts only when the user clicks **Open camera**.
