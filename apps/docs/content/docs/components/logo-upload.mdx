## Installation

```npm
npx shadcn@latest add @uploadcn/logo-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and the shadcn `card` component, then copy:

<ComponentSource name="logo-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { LogoUpload } from "@/components/logo-upload"
```

```tsx
<LogoUpload name="Acme Inc" onSuccess={(item) => saveLogo(item.result)} />
```

It's a single-file uploader: choosing a new file replaces the current one.
