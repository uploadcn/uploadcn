## Usage

```tsx
import { ImageMetadataUpload } from "@/components/image-metadata"
```

```tsx
<ImageMetadataUpload
  onSave={(images) =>
    images.map(({ item, alt, caption }) => ({
      key: item.result?.key,
      alt,
      caption,
    }))
  }
/>
```

Alt text and captions are stored on each item's `meta` with `uploader.update(id, { meta })`, so they survive re-renders and travel with the item.
