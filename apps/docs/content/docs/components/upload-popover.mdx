## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/upload-popover
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and the shadcn `popover` component, then copy:

<ComponentSource name="upload-popover" />

</Tab>
</Tabs>

## Usage

```tsx
import { UploadPopover } from "@/components/upload-popover"
```

```tsx
<UploadPopover label="Attachments" maxSize={10 * 1000 * 1000} />
```

Uploads keep going when the popover closes; the ring on the trigger shows their progress.
