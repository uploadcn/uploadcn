## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/paper-plane-button
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="paper-plane-button" />

</Tab>
</Tabs>

## Usage

```tsx
import { PaperPlaneButton } from "@/components/paper-plane-button"
```

```tsx
<PaperPlaneButton>Send to client</PaperPlaneButton>
```

The label is a live region, so screen readers hear Sending, Sent and errors.
