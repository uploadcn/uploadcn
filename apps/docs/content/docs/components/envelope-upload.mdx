
</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

</Tab>

## Usage

```tsx
import { EnvelopeUpload } from "@/components/envelope-upload"
```

```tsx
<EnvelopeUpload recipient="Acme Legal" accept="application/pdf" />
```

The flap is a 3D `rotateX` and the seal uses a spring. With reduced motion, states change instantly.
