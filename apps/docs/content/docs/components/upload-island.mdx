## Usage

```tsx
import { UploadIsland } from "@/components/upload-island"
```

```tsx
<UploadIsland maxFiles={10} />
```

The pill is the dropzone itself, so it's both a button and a drop target. The shape animates with `motion`'s `layout`; content cross-fades with a blur. It expands on hover and on keyboard focus, and its accessible name always describes the progress.
