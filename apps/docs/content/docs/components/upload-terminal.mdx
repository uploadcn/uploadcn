## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/upload-terminal
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="upload-terminal" />

</Tab>
</Tabs>

## Usage

```tsx
import { UploadTerminal } from "@/components/upload-terminal"
```

```tsx
<UploadTerminal title="deploy/assets" />
```

The window is always dark, whatever the theme. The log is an `aria-live` list and scrolls to the newest line.
