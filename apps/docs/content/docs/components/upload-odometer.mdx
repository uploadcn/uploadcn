## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/upload-odometer
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="upload-odometer" />

</Tab>
</Tabs>

## Usage

```tsx
import { UploadOdometer } from "@/components/upload-odometer"
```

```tsx
<UploadOdometer maxFiles={50} />
```

Digits are decorative (`aria-hidden`); a visually hidden copy of each value is read instead.
