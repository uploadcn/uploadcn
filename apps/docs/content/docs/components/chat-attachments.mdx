## Usage

```tsx
import { ChatAttachments } from "@/components/chat-attachments"
```

```tsx
<ChatAttachments
  onSend={async ({ text, attachments }) => {
    await sendMessage({ text, files: attachments.map((item) => item.result) })
  }}
/>
```

Images are downscaled to 1568px WebP before upload (the size vision models work with), which makes attachments upload several times faster. Paste is scoped to the composer.
