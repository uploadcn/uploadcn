
</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and the shadcn `table` component, then copy:

<ComponentSource name="upload-table" />

</Tab>
</Tabs>

## Usage

```tsx
import { UploadTable } from "@/components/upload-table"
```

```tsx
<UploadTable title="Project files" />
```

Rows are rendered with `UploadItemContext`, so every `UploadItem*` part (status, progress, actions, error) works inside table cells. The drop target is an [`UploadOverlay`](/docs/components/upload#overlay).
