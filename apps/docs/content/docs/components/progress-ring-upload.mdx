## Installation

<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/progress-ring-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

</Tab>

## Usage

```tsx
import { ProgressRingUpload } from "@/components/progress-ring-upload"
```

```tsx
<ProgressRingUpload />
```

The ring and the number share one `useSpring`, so they never drift apart. The caption under the ring is an `aria-live` region with files, bytes and time left.
