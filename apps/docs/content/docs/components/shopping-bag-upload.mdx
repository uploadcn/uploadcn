## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/shopping-bag-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="shopping-bag-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { ShoppingBagUpload } from "@/components/shopping-bag-upload"
```

```tsx
<ShoppingBagUpload maxFiles={12} />
```

Pair it with [Product Media](/docs/components/product-media-upload) to order the photos afterwards.
