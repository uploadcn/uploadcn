## Usage

```tsx
import { RippleDropzone } from "@/components/ripple-dropzone"
```

```tsx
<RippleDropzone title="Drop to upload" />
```

It uses the dropzone's `render` prop to read `isDragging` and `isDragReject`; rings turn red for files that don't match `accept`.
