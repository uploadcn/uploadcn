## Usage

```tsx
import { UploadField } from "@/components/upload-field"
```

```tsx
<Controller
  name="attachments"
  control={form.control}
  render={({ field, fieldState }) => (
    <UploadField
      label="Attachments"
      required
      maxFiles={3}
      error={fieldState.error?.message}
      onChange={field.onChange}
      onBlur={field.onBlur}
      onUploadingChange={setIsUploading}
    />
  )}
/>
```

The value is a list of object keys, not files: uploads happen while the user fills in the form, so submitting is instant.
