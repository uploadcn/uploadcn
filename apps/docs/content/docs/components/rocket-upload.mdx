## Usage

```tsx
import { RocketUpload } from "@/components/rocket-upload"
```

```tsx
<RocketUpload accept={[".zip", ".tar.gz"]} />
```

Altitude is a spring driven by the overall percent, so the climb is smooth even when progress arrives in bursts. The status line in the corner is an `aria-live` region with bytes and time left. Smoke and engine flicker are skipped with reduced motion.

It uploads through your [adapter](/docs/storage) like every other component, so it works with S3, R2, Cloudinary, local disk or your own API.
