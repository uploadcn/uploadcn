## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/upload-morph-button
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="upload-morph-button" />

</Tab>
</Tabs>

## Usage

```tsx
import { UploadMorphButton } from "@/components/upload-morph-button"
```

```tsx
<UploadMorphButton accept="application/pdf">Upload report</UploadMorphButton>
```

The width animates with `motion`'s `layout`, and the label cross-fades between states. The state is announced through `aria-live`.
