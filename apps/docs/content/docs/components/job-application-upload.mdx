## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/job-application-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and the shadcn `button`, `input` components, then copy:

<ComponentSource name="job-application-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { JobApplicationUpload } from "@/components/job-application-upload"
```

```tsx
<JobApplicationUpload
  role="Staff Engineer"
  onSubmit={(application) => apply(application)}
/>
```

Submit stays disabled until the resume has uploaded, so you never receive an application without one.
