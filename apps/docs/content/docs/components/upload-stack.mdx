## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/upload-stack
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="upload-stack" />

</Tab>
</Tabs>

## Usage

```tsx
import { UploadStack } from "@/components/upload-stack"
```

```tsx
<UploadStack maxFiles={10} />
```

Collapsed cards beyond the third are `inert`, so keyboard users never land on a hidden card; focusing the stack expands it.
