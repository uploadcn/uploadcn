## Usage

```tsx
import { BatteryUpload } from "@/components/battery-upload"
```

```tsx
<BatteryUpload noun="photos" />
```

Five cells share one spring, each filling its fifth of the progress. Failed uploads turn the cells destructive. The caption is an `aria-live` region with counts, bytes and time left.

It uploads through your [adapter](/docs/storage) like every other component, so it works with S3, R2, Cloudinary, local disk or your own API.
