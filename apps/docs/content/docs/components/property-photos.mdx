## Usage

```tsx
import { PropertyPhotos } from "@/components/property-photos"
```

```tsx
<PropertyPhotos
  rooms={[
    "Exterior",
    "Living room",
    "Kitchen",
    "Bedroom",
    "Bathroom",
    "Garden",
  ]}
  recommended={15}
  onChange={(photos) => save(photos)}
/>
```

Room tags live on each item's `meta.room` (set with `uploader.update`), and the room picker is a native `<select>` so it works everywhere, including screen readers.
