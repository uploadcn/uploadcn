## Usage

```tsx
import { ReceiptUpload } from "@/components/receipt-upload"
```

With OCR, the form fills itself. Textract's `expense` model and Azure's
`prebuilt-receipt` return the fields directly; other engines are read from the text:

```tsx
import { ocrEndpoint } from "@uploadcn/core"

;<ReceiptUpload
  recognize={ocrEndpoint("/api/ocr")} // npx shadcn@latest add @uploadcn/ocr-route
  onSubmit={(expense) => createExpense(expense)}
/>
```

Or extract the fields yourself, with any API or model:

```tsx
<ReceiptUpload
  extract={async (item) => {
    const response = await fetch(`/api/receipts/${item.result.key}/ocr`)
    return response.json() // { merchant, date, amount, category }
  }}
  onSubmit={(expense) => createExpense(expense)}
/>
```

On phones the picker opens the rear camera (`capture="environment"`). Fields the user already typed are never overwritten. `receiptFromOcr(result)` is exported if you want the same mapping elsewhere. See the [OCR guide](/docs/guides/ocr) for providers.
