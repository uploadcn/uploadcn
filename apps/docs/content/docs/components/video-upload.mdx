## Usage

```tsx
import { VideoUpload } from "@/components/video-upload"
```

```tsx
<VideoUpload maxDuration={600} maxSize={2_000_000_000} />
```

With the default `s3Adapter`, files of 64 MB and more switch to multipart: parallel parts, per-part retry, and pause/resume.
