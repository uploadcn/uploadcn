## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/folder-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="folder-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { FolderUpload } from "@/components/folder-upload"
```

```tsx
<FolderUpload name="Q3 Reports" maxFiles={20} />
```

The folder opens with CSS on hover and while dragging (`group-data-dragging`), and the flying files use `motion`. With `prefers-reduced-motion`, files don't fly and the folder doesn't tilt.
