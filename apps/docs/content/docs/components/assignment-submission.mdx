## Usage

```tsx
import { AssignmentSubmission } from "@/components/assignment-submission"
```

```tsx
<AssignmentSubmission
  title="Essay: The Industrial Revolution"
  due={new Date("2026-11-01T23:59:00")}
  onSubmit={(files) => turnIn(files)}
/>
```

The countdown renders on the client only, so server and client HTML always match.
