## Usage

```tsx
import { ProductMediaUpload } from "@/components/product-media-upload"
```

```tsx
<ProductMediaUpload
  maxFiles={8}
  onChange={(images) => setImages(images.map((image) => image.result))}
/>
```

Every tile has keyboard-accessible buttons to make it the cover or move it, so reordering doesn't depend on drag and drop. Order is kept in the component and reported through `onChange`.
