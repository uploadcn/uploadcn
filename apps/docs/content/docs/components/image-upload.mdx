## Usage

```tsx
import { ImageUpload } from "@/components/image-upload"
```

```tsx
<ImageUpload crop compress maxWidth={2000} />
```

Cropping happens inside the upload pipeline: each image waits in the `validating` state while its crop dialog is open, and several images are cropped one after another. Skipping a crop uploads the original.
