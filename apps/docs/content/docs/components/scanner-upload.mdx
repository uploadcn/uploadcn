## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/scanner-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="scanner-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { ScannerUpload } from "@/components/scanner-upload"
```

```tsx
<ScannerUpload label="Scan your ID" />
```

On phones the picker opens the rear camera. The frame has an ID-card aspect ratio (1.586:1).
