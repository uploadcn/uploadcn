## Usage

```tsx
import { CameraUpload } from "@/components/camera-upload"
```

```tsx
<CameraUpload facingMode="user" maxFiles={5} />
```

`CameraCapture` is exported too, drop it inside any `<Upload>` to add a viewfinder. The [`useCamera`](#usecamera) hook releases the camera on unmount.

## useCamera

The hook behind the viewfinder. It's installed with the component.

```tsx
const { videoRef, status, start, stop, flip, capture } = useCamera()

<video ref={videoRef} muted playsInline />
<button onClick={() => start()}>Open camera</button>
<button onClick={async () => uploader.add([await capture()])}>Snap</button>
```

`status` is `idle`, `starting`, `ready`, `denied`, `unavailable` or `error`.
