## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/polaroid-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="polaroid-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { PolaroidUpload } from "@/components/polaroid-upload"
```

```tsx
<PolaroidUpload maxFiles={8} />
```

Each photo gets a stable tilt derived from its id, so re-renders never make it jump.
