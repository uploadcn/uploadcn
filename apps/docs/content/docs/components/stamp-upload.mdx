## Usage

```tsx
import { StampUpload } from "@/components/stamp-upload"
```

```tsx
<StampUpload stamp="Filed" />
```

The four most recent documents stay on the pile with small fixed tilts, so the server and client render the same. Each stamp carries the date in the user's locale. With reduced motion the stamp fades in instead of slamming down.

It uploads through your [adapter](/docs/storage) like every other component, so it works with S3, R2, Cloudinary, local disk or your own API.
