
</Tab>

```npm

```

## Usage

```tsx
import { UploadConfetti } from "@/components/upload-confetti"
```

```tsx
<Upload className="relative">
  <UploadDropzone />
  <UploadQueue />
  <UploadConfetti />
</Upload>
```

It's a part, not a whole uploader: it reads the nearest `<Upload>`. Colors come from `--primary` and `--chart-1…5`, so it matches every theme. Give the parent `relative`.
