## Usage

```tsx
import { IdentityVerification } from "@/components/identity-verification"
```

```tsx
<IdentityVerification onSubmit={(files) => verify(files)} />
```

Built on [`UploadSlot`](/docs/components/upload#slots): one uploader, a named slot per document, each tagged with `meta.slot`. Store identity documents in a private bucket and serve them with short-lived signed URLs.
