## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/cloud-dropzone
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="cloud-dropzone" />

</Tab>
</Tabs>

## Usage

```tsx
import { CloudDropzone } from "@/components/cloud-dropzone"
```

```tsx
<CloudDropzone maxSize={100 * 1000 * 1000} />
```

The fill is an SVG clip path driven by `useUploadProgress`.
