## Usage

```tsx
import {
  GlobalDropzone,
  UploadProvider,
  UploadQueuePanel,
} from "@/components/global-upload"
```

```tsx
// app/layout.tsx
<UploadProvider persist>
  {children}
  <GlobalDropzone />
  <UploadQueuePanel />
</UploadProvider>
```

Any component under the provider can add files with `useUploadContext().addFiles(files)`. Uploads keep running during client-side navigation because the provider stays mounted. `GlobalDropzone` ignores drops already handled by an inner dropzone.
