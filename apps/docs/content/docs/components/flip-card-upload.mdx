## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/flip-card-upload
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="flip-card-upload" />

</Tab>
</Tabs>

## Usage

```tsx
import { FlipCardUpload } from "@/components/flip-card-upload"
```

```tsx
<FlipCardUpload title="Upload your contract" accept="application/pdf" />
```

The hidden face is `inert`, so keyboard focus never lands on the side you can't see.
