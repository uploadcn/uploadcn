## Usage

```tsx
import { CsvImport } from "@/components/csv-import"
```

```tsx
<CsvImport
  columns={[
    { key: "email", label: "Email", required: true },
    { key: "name", label: "Name" },
  ]}
  onSuccess={(item, preview) => startImportJob(item.result, preview.rowCount)}
/>
```

Uploading only starts when the user clicks **Import**, and stays disabled while required columns are missing. Parsing is a small RFC 4180 parser, swap in Papa Parse for exotic files.
