## Usage

```tsx
import { DeliveryUpload } from "@/components/delivery-upload"
```

```tsx
<DeliveryUpload destination="Warehouse 4" />
```

The truck's position is a spring on the overall percent, and the road markings and wheels only move while it's driving. The status line says where the files are going and when they'll arrive.

It uploads through your [adapter](/docs/storage) like every other component, so it works with S3, R2, Cloudinary, local disk or your own API.
