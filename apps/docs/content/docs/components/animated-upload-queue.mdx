## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/animated-upload-queue
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="animated-upload-queue" />

</Tab>
</Tabs>

## Usage

```tsx
import { AnimatedUploadQueue } from "@/components/animated-upload-queue"
```

```tsx
<AnimatedUploadQueue maxFiles={20} />
```

Built from the same `UploadItem` parts as the static queue, wrapped in `AnimatePresence` for exit animations.
