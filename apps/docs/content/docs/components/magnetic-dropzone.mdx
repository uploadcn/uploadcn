## Installation

<Tabs items={["Command", "Manual"]}>
<Tab value="Command">

```npm
npx shadcn@latest add @uploadcn/magnetic-dropzone
```

</Tab>
<Tab value="Manual">

Install [Upload](/docs/components/upload) and `motion`, then copy:

```npm
npm install motion
```

<ComponentSource name="magnetic-dropzone" />

</Tab>
</Tabs>

## Usage

```tsx
import { MagneticDropzone } from "@/components/magnetic-dropzone"
```

```tsx
<MagneticDropzone strength={0.35} />
```

Pointer and `dragover` events feed a spring; it doesn't move at all with `prefers-reduced-motion`.
