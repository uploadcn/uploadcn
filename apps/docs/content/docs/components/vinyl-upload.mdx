## Usage

```tsx
import { VinylUpload } from "@/components/vinyl-upload"
```

```tsx
<VinylUpload maxSize={200 * 1024 * 1024} />
```

The record has momentum: its speed is a spring, so it spins up when uploads start and coasts to a stop instead of freezing. The tonearm angle tracks the overall percent. With reduced motion the record stays still and the arm jumps to its position.

It uploads through your [adapter](/docs/storage) like every other component, so it works with S3, R2, Cloudinary, local disk or your own API.
