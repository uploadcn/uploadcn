## Usage

```tsx
import { DocumentIngest } from "@/components/document-ingest"
```

```tsx
<DocumentIngest
  ingest={async (item, { setStage, signal }) => {
    const { jobId } = await startIngestion(item.result.key, { signal })
    for await (const stage of watchJob(jobId, { signal })) setStage(stage)
  }}
/>
```

Stages are `upload`, `parse`, `chunk`, `embed` and `index`. Report them from polling, server-sent events or webhooks: the UI only reflects what your backend says.
